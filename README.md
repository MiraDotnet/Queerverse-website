# queerverse.net

The website for the Queerverse Minecraft server. Plain HTML and CSS, hosted on GitHub Pages.

## Changing things

- **Text:** each page is its own file (`index.html`, `rules.html`, `apply.html`, `members.html`). The yellow boxes are spots that still need writing. Delete the `class="todo"` part once you've rewritten one.
- **Screenshots:** upload images into the `images` folder using the names shown in the empty boxes (`home-top.jpg`, `build-1.jpg` to `build-7.jpg`, plus `rules-top.jpg`, `apply-top.jpg`, `members-top.jpg` for the other pages). They appear on their own.
- **Colors:** the top of `style.css` has all of them in one place.
- **Form link:** search for `YOUR-FORM` and swap in the real Google Form link.
- **Members:** see the note at the top of `members.html`.

Edits made on github.com go live a minute or two after you commit them.
